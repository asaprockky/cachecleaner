## How it is made

`index.html` contains a **fake Pulberry app** (home, application steps 1–2, processing, offers, loan types, payment, map) built in plain HTML/CSS, placed inside a 3D phone. A scripted user journey (finger taps, slider drag, scrolls, screen pushes, counters, success states, confetti) is driven frame-by-frame by `window.seek(t)`, captured with headless Chromium, and encoded with ffmpeg. Nothing inside the phone is a raster crop except the loan-type photos and the map, which come from the lossless Play Store screenshots.

Journey (seconds):

| Time | Beat |
|---|---|
| 0–2.6 | Logo slams in with particles, "Pul kerakmi?" letter by letter |
| 2.6–5.4 | Phone flies in; six partner logos orbit it in 3D; "+100" counter |
| 5.4–6.2 | Home screen: "Barcha kreditlar bitta ilovada"; tap "Kredit olish" |
| 6.2–9.8 | Step 1: finger drags the amount slider (counts to 50 000 000); step 2: pick "12 oy"; "Yuborish" |
| 9.8–12.6 | Processing ring 0→100 %, approved check, success chime, confetti, toast "3 ta yangi taklif" |
| 12.6–16.8 | Offers list: amounts count up, scroll, open Hamroh MMT, accept (coin chime) |
| 16.8–20.2 | Loan types: four cards flip in with slow Ken Burns on photos, scroll |
| 20.2–24.0 | Payment screen: amounts count, tap "To'lash", "To'landi!" success overlay |
| 24.0–27.6 | Map with partner pins and ripples; 12 city chips pop in around the phone; licence line |
| 27.6–32.2 | Outro: logo spin, stars fill to 4.1, Google Play badge shine, @pulberry.uz |

## Sound

Original synthesized track (120 BPM, two drops) + 11 SFX (whoosh, impact, pops, ticks, coin, success chime, swipe, click, shine, riser), all generated by `audio_gen.py`. Mix normalised to −14 LUFS / −1 dBTP. No voice-over. Replace `audio/music.wav` with a licensed track if you want real music.

## Rebuild

```bash
python3 audio_gen.py                                  # audio/
node render.js --lang uz --scale 2 --out frames_uz    # ~15 min
./mix.sh uz                                           # out/pulberry_uz_4k.mp4 + _1080p.mp4
```

Text lives in the `COPY` object at the top of `index.html`; timings in the `T` object.
